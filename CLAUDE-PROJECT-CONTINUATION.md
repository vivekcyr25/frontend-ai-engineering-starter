# Claude Project Continuation

Keep the existing Claude Project as the long-term workspace for the portfolio. Future case studies should continue within that project rather than starting a new project and rebuilding context from scratch.

The existing project already contains the portfolio’s important guardrails:

- proof statement;
- target audience;
- primary CTA;
- voice card;
- visual identity;
- case-study style;
- content map;
- portfolio constraints.

That context is useful because it keeps new writing connected to the same evidence-first portfolio: technical, direct, practical, concise, and honest about limitations.

## How to continue the project

1. Start a new conversation inside the existing Claude Project for the new case study.
2. Provide only the new project’s source material: notes, code paths, logs, screenshots, verified links, measured results, decisions, and known limitations.
3. Ask Claude to follow the established three-beat format: **The Problem**, **What I Did**, and **What Came of It**.
4. Require `[TO BE COLLECTED WHEN COMPLETE]` for every unknown future result, screenshot, metric, or link.
5. Review the draft against the real repository and evidence before placing it in the portfolio.
6. Add any genuinely new, reusable portfolio rule to the existing project context only after it has been reviewed. Do not recreate or duplicate the whole project context for each case.

## Preservation rule

Claude can help organize, draft, and critique. The project owner remains responsible for technical facts, personal contribution, metrics, screenshots, links, limitations, and the final publishing decision.

For the next case, use the existing context plus the new capstone evidence; do not ask the project to invent a final outcome while the work is ongoing.
