# Portfolio Maintenance

## How to Add the Next Case

Use the repeatable process in [NEXT-CASE-STUDY-WORKFLOW.md](NEXT-CASE-STUDY-WORKFLOW.md): create the case in the existing project structure, gather real evidence, write the three beats, add supporting content, review claims, publish, and preserve the established visual system.

The required case-study structure is:

1. **The Problem** — the real problem and why it mattered.
2. **What I Did** — personal contribution, implementation, decisions, and trade-offs.
3. **What Came of It** — verified outcome/evidence and remaining limitations.

Do not create a new page type unless the existing portfolio structure genuinely cannot support the case. Do not change global styles unless necessary. Reuse existing fonts, colors, spacing, cards, CTAs, image treatment, and navigation.
