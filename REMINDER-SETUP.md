# Reminder Setup: FlyRank AI Internship Capstone Case Study

---

## Reminder Title

**Add FlyRank AI internship capstone case study**

---

## Suggested Timing

**Two days after the internship / capstone work is actually complete.**

The two-day gap gives time to:

- export final screenshots while the working environment is still available;
- collect the final GitHub repository URL and confirm public access;
- note engineering decisions while they are still fresh;
- draft the three-beat case with real, finished evidence rather than speculation.

Do not act on this reminder until the capstone work is genuinely finished.
Do not draft the case study from an incomplete project.

---

## Purpose

To gather all final evidence for the FlyRank AI internship capstone and add the
completed case study to the portfolio as a fourth case on the `/work` page.

The case must be written and reviewed before it is published. The reminder is the
trigger to begin gathering evidence. It is not a trigger to publish immediately.

---

## What Must Be Ready Before Acting on This Reminder

Do not open the portfolio or start drafting until all of the following are confirmed
or explicitly documented as outside scope:

| Item | Status at reminder time |
| :--- | :--- |
| Capstone project is fully complete and working | Confirm before starting |
| GitHub repository URL (public or restricted-access link for reviewers) | Collect |
| Live deployment URL (if the project has one) | Collect or document as N/A |
| At least 1 key implementation screenshot | Collect |
| Architecture or technical diagram showing the system or pipeline | Collect or create |
| List of key engineering decisions made during the internship | Write from memory/notes |
| Evidence of AI-assisted workflow steps and my verification actions | Collect from logs/notes |
| At least 1 verification or testing artifact (test log, coverage report, review note) | Collect |
| Plain-language description of the final outcome | Write from real results |
| Honest list of limitations or things not yet completed | Write accurately |

If any item in the table above cannot be collected, document it as a limitation in
the case study rather than omitting it or inventing a substitute.

## How to Set This Reminder

This file does not create a reminder. Create the reminder manually in your preferred
calendar or task tool immediately after reading this file.

Suggested options:

- **Google Calendar:** Create an event titled "Add FlyRank AI internship capstone
  case study" on the date two days after the expected completion of the internship.
  Set a notification for the morning of that day.

- **Notion / Linear / Todoist:** Create a task titled "Add FlyRank AI internship
  capstone case study" with a due date two days after internship completion and link
  to `NEXT-CASE-STUDY.md` in the task description.

- **GitHub Issues:** Open an issue in this repository titled "Add FlyRank AI internship
  capstone case study" and add the label `portfolio-maintenance`. Close it only after
  the case is live and verified.

**The reminder has not been created. You must create it manually.**

## What to Do When the Reminder Fires

1. Confirm the capstone work is complete.
2. Collect all evidence listed in the table above.
3. Open `NEXT-CASE-STUDY.md` and follow Steps 1 through 6.
4. Draft the three-beat case: THE PROBLEM, WHAT I DID, WHAT CAME OF IT.
5. Add the case to the portfolio at route `/work/flyrank-internship`.
6. Review against the checklist in STEP 5 of `NEXT-CASE-STUDY.md`.
7. Publish using the process in STEP 6 of `NEXT-CASE-STUDY.md`.
8. Verify the live page.
9. Mark this reminder as complete and close or delete the reminder item.
