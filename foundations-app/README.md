# Foundations App

Next.js (App Router) foundations phase for the FlyRank AI internship portfolio.

## Stack

- Next.js 16 + React 19
- TypeScript
- Tailwind CSS v4
- Server Components by default; Client Component only for interactive nav (`SiteHeader`)

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Routes

See `ASSIGNMENT-SUBMISSION.md`.

## Environment

Copy `.env.example` to `.env.local` if needed. Do not commit secrets.

## Deploy (Vercel)

1. Push `foundations-app/` to GitHub.
2. Import the repo in Vercel.
3. Set **Root Directory** to `foundations-app`.
4. Deploy — preview URLs should build on every push.
